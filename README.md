# HIS 315K Midterm Study Guide

Interactive study guide. Open index.html in a browser. Progress is saved in browser local storage and is not uploaded to GitHub.

Course materials remain the property of their respective authors.

## Narration

Each of the eight sections has a pre-generated MP3 narrated with Luke's existing Chatterbox voice clone. The audio player supports pause, seeking, playback speed, and continuing through the remaining sections. It never starts automatically on page load.

Model weights, studio reference recordings, and credentials are not included. The website plays static audio and does not call a voice API or require a running Windows computer.
